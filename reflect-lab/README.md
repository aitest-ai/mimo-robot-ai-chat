# Mimo 心晴之鏡｜聊天式 SEL 練習

**體驗網址：** https://mimo-reflection-lab.vercel.app/

這是國小中高年級的情緒覺察、事件澄清與換位反思學習原型，**不是心理治療、心理診斷、AI 心理師或校園霸凌調查工具**。

## v0.4：機器人為主角的自然對話介面

- 首頁不再顯示左側課程選單、進度條與七關步驟，改為大尺寸 Mimo、持續的表情、目前的一句話、簡潔回覆選項及輸入區。
- 孩子說完後 Mimo **立即接話，接著只問一個問題**。不需一直按「下一題」。
- SEL 教學順序留在背景：傾聽 → 辨識感受 → 自主安定 → 回顧事件 → 分開觀察與猜測 → 探索不同角度 → 帶走一個方法。可跳過部分階段或自行決定先休息。
- 自由文字與快捷選項可混用，完整聊天紀錄預設收合，隨時可以展開。
- 「呼吸圓圈」改為孩子主動啟動的聊天工具，8 秒一輪，4 秒吸氣／4 秒吐氣，可暫停，也尊重減少動態效果設定。
- 「換位小鏡子」變成**孩子自行選擇**，可跳過；表情由孩子挑選，角色不假裝知道現實中的人真正怎麼想。
- 找大人幫忙固定出現在操作畫面；安全字詞檢查可優先引導真人求助，但**不能保證找出全部風險，不具備危機通報能力**。

## Gemini 模式與固定引導模式

前端 `chat.js` 目前預設為**虛構故事體驗**（不傳輸文字到模型）。教師點右上角齒輪，輸入測試碼並確認僅使用虛構案例後，若 Vercel `GEMINI_API_KEY` 已設定，才會呼叫 `/api/reflect`，由 Gemini 2.5 Flash 回覆：

- **reply**：根據本題與少量上下文產生一段具體回應，不追問、說教或替人判責。
- **question**：依隱藏的下一個教學目的，產生**一個**自然、短的問題。
- **face**：Mimo 表情（限制在六種可控的表情狀態）。
- **needsAdult**：有風險時優先建議找真正的大人。

雲端回覆失敗、模型輸出不合格式或服務尚未啟用時，會使用本機的文字引導，而不把它冒充為 AI 生成。

目前需在 Vercel 設定 `GEMINI_API_KEY` 才能真正運行 Gemini。部署資訊與兒童資料保護請參考 [AI_PILOT.md](./AI_PILOT.md)、[DESIGN.md](./DESIGN.md)。

## 技術結構

| 檔案 | 目前用途 |
|---|---|
| `index.html` | 最新的機器人中心式聊天頁面 |
| `chat.css` | 平板／手機聊天版面與機器人表情、呼吸動畫 |
| `chat.js` | 自然對話控制、快捷回覆、自願換位、危險分流、Gemini opt-in |
| `api/reflect.mjs` | 伺服器 Gemini 2.5 Flash、短回覆與單一追問結構化輸出 |
| `app.js`、`guided.js`、`style.css` | 舊版七階段與逐題版保留備查，首頁已不載入 |

## 驗收和限制

- 已以程式模擬測試完整虛構美勞課聊天、心情、呼吸、事實與想法、換位、行動與結束、安全求助；模型端的結構化輸出與安全分流以假資料測試。
- **尚未**用真正的學生語音、真實校園衝突事件或 AI 端到端測試驗證教育成效。
- 只有使用者主動啟用測試模式才會送出虛構案例文字；不要輸入真實姓名、班級、學校、家庭或同學的敏感經歷。
- 現階段不儲存資料庫或瀏覽器本機紀錄；重新整理會清除互動，但第三方平台仍可能保留必要的中繼資料。
- 正式學校導入須先完成輔導專業與兒童心理安全審查、隱私與監護人／學校程序、持續霸凌或危險事件的真人接手 SOP。

## v0.5：高情緒壓力測試後的安全與支持修正（2026-10-12）

已在正式部署的 `chat.js` 與 `api/reflect.mjs` 加入雙層安全分流。學生提及想掃落物品時先安全暫停；反覆被取笑、無助或不想上學時先確認安全；可能對自己或別人立即造成傷害時優先成人協助。拒絕冷靜、呼吸、原諒或換位思考時不再強迫進入該流程。Mimo 在高情緒狀況維持安定、專注的表情。

- Gemini 一般回應仍保留；安全風險規則不需要等待雲端 AI 成功。
- API 僅接受系統允許的 SEL 問題目標，拒絕 HTTP 呼叫端任意指定提示指令。
- 進行過正式網站的 Playwright 瀏覽器測試（當時 12/12）與另一次 9/9 繁體中文安全語句抽測；完整紀錄與驗收界線：[QA_STRESS_FIXES_20261012.md](./QA_STRESS_FIXES_20261012.md)。
- 這仍是虛構案例教學原型，**非已驗證之心理諮商／危機處置系統，無自動通報能力**。
