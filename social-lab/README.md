# Mimo 人際練習室 — Social Lab

一個為國小學生設計的 **人際互動與說話練習** 概念 Demo。透過虛構角色的表情、語句回應、不同觀點與自我修正，練習在尊重別人的同時表達自己的需要。

## 立即試玩

如果主儲存庫已啟用 GitHub Pages（Source = Deploy from a branch、main、/(root)），進入：

https://aitest-ai.github.io/mimo-robot-ai-chat/social-lab/

也可以直接下載 `index.html`，以瀏覽器離線開啟。

## 目前有什麼（第二版互動小劇場）

1. 三個有具體時間、地點、人物的校園短劇：「最後十分鐘」、「水壺倒下的那一秒」、「誰拿走了我的橡皮擦？」。
2. **每關四幕故事鋪陳**：情境、轉折、旁人對話、當事人的一句話；學生自己按下一幕，也可以直接跳過。
3. 三位虛構同學使用不同機殼配色，搭配班級場景、舞台線索及緩慢穩定的表情動畫。
4. 每關三種選擇，選完會先看**故事後續與對方接著說的話**，再進入反思，不會立即跳出對錯分數。
5. 可反覆選擇、觀察不同分支，並提供「看另一種可能」以避免將表情當成必然反應。
6. 學生可在任何一關自行撰寫句子，用三個問題自我檢核；這不是 AI 自動評分。
7. 全部操作採手動推進、不強迫等待；可使用手機，並支援作業系統的減少動態效果設定。

## 重要設計原則

- **表情不是讀心術。** 即使同一句話，在不同關係或情境下，別人也可能有不同感受。請鼓勵學生用傾聽與詢問確認。
- **不是讓所有角色都開心的遊戲。** 禮貌拒絕、保護界線，即使對方表情不悅，仍可能是好溝通。
- **不要把人分成「壞孩子」與「好孩子」。** 評估特定行為與話語，不替人貼標籤。
- **不能用於心理診斷或學生紀律判決。** 所有反應由編寫者固定設計，並非 AI 辨識他人真實情緒。
- **保護兒少隱私。** 本試作沒有資料庫、帳號、API 或追蹤；輸入文字不會主動儲存或送出。但公用設備使用時仍須留意瀏覽器與裝置風險。
- **正式版須教師與兒少專家共同審核**：情境正確性、文化與語言差異、歧視偏見風險、兒童易用性，並建立安全通報與求助機制。

## 與真正 AI 的差別

這是以四幕短劇組織的固定分支靜態 HTML 原型，不呼叫 Ollama，也未直接使用 `robot-heads` 套件；機器人以 SVG/CSS 呈現四類情緒狀態，未來可以把狀態機移植到原作者 React 元件，再串接受保護的 AI 後端，產生多輪角色扮演與教師可審核的回饋。
