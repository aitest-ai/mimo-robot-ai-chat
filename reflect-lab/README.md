# Mimo 心晴之鏡 · SEL Reflection Lab

一套以**情緒覺察—事件澄清—換位反思—行動遷移**為主軸的國小中高年級互動原型，定位是「SEL 學習輔助」，**不是 AI 諮商師、心理治療、霸凌調查或正式危機服務**。

## 線上體驗

**https://mimo-reflection-lab.vercel.app/**

單獨 Vercel 專案的根目錄是 `reflect-lab/`，與 `social-lab/` 原本的校園短劇分開部署。Github 的 AI 開發分支為 `feature/mimo-sel-reflection-ai`，由當前 main 建立。

## 七個步驟

1. **先確認安全**：一般同學衝突、還不確定，或持續欺負／威脅。最後一類優先找大人，停止一般角色換位。
2. **心情天氣與強度**：六種天氣、可選多個情緒詞、1–5 感受強度。
3. **給自己空間**：接納感受，自主選呼吸、安靜休息、傾聽或求助；不強制情緒降低。
4. **我的故事**：自由敘述，記下當時說過的話；提供一則虛構的美勞課示範。
5. **事實放大鏡**：區分自己觀察到的事件、對他人意圖的猜測、仍不知道的內容。
6. **換位小鏡子**：學生自己確認原話及選擇可能的表情；假設被聽到可能的感受，以及對方、旁觀者可能不同的角度。
7. **成長卡**：練習設界線、說出需要、修復、休息或找大人，留下未來類似情境可以嘗試的一句話。

## 試玩建議

請務必按「✨ 使用美勞課的虛構故事示範」再往後測試；這版只適合用虛構事件做介面與流程驗收。不要輸入真實學校、班級、姓名、家庭衝突或個資。

如果孩子遇到疑似霸凌、虐待、威脅、持續排擠或其他風險，應優先找可信任的成年人與學校專業人員，正式作業依學校程序進行。

## 目前技術狀態

- 使用原生 HTML/CSS/JS，無需安裝依賴、可部署在 GitHub Pages 或 Vercel。
- 暫時沒有呼叫大語言模型、SenseVoice 或任何 API；**現在所有回應都是教育設計者撰寫的固定引導**。
- 不使用 localStorage、cookie、資料庫、後端請求或追蹤程式儲存輸入。
- 表情僅呈現學生自己選的**假設情境**，不是推測對方心理、不是診斷學生情緒。
- 每個階段有返回入口；可以隨時點「我現在需要大人幫忙」。
- GitHub 上的功能與模擬互動已有初步程式測試；正式平板／手機與不同瀏覽器上的視覺及無障礙驗收，還需另外完成。

## AI 接入及研究規格

詳見 [DESIGN.md](./DESIGN.md)，包含 CASEL、RULER、情緒教練、兒少安全與真人介入、Fact Lens 資料標註、Perspective Engine 不讀心原則、Mirror Actor 表情控制及未來研究測驗建議。

**重要原則**：情緒沒有對錯，行為可以反思；觀點取替不等於為不當行為辯護；AI 只能提供假設和問題，不能直接判定現實中的責任。

## 隱私提醒

目前僅供教師或研究者使用虛構案例進行內部測試，不應開放學生輸入真實經歷。在兒少隱私、法遵、輔導專業審查、AI 安全測試及校園 SOP 完成前，不應作為正式國小輔導工具。
## v0.2：一問一答 × 即時表情回饋（2026-10-12）

使用中的首頁已從舊版 `app.js` 改用 `guided.js`。`app.js` 保留作為舊版備份，不再載入。保留原本的七個 SEL 階段，但拆成 **20 個依序呈現的單題互動**，最後再展示成長卡。

- 畫面一次只出現一題。每一題有獨立的選擇、滑桿或文字輸入。
- 選擇題選完就會顯示 **Mimo 的表情與一句話回饋**，並維持直到學生進下一題；文字題要先按「告訴 Mimo」。
- 情緒天氣→強度→情緒名稱，事件敘述→原話，事實→推測→未知，換位鏡與成長卡，各自拆成單題。
- 情緒很強烈也不會被要求立刻變晴天；必要時可先找大人。學生可以略過不想回答的敘述題。
- 選擇『跟著圓圈呼吸』後顯示 **8 秒呼吸動畫：4 秒擴大／吸氣 + 4 秒縮小／吐氣**，附即時文字節奏、暫停／繼續和『我準備好繼續了』。
- 如果裝置啟用 **減少動態效果**，呼吸動畫預設不自動播放，但學生可明確按『開始動畫』啟動。
- 換位鏡使用學生自己選擇的表情；機器人不會自動判定孩子或同學真正的情緒。
- 不是自由對話 AI，目前所有回饋都由固定教學規則提供；不評分、不上傳、不儲存輸入。

### 功能驗收

已透過模擬 DOM 驗證安全確認→天氣→強度→情緒→情緒調節→呼吸→敘述→事實→猜測→未知→換位→回應方案→成長卡的 20 題逐題流程，每題均有表情回饋。**尚未在真實平板瀏覽器驗證視覺動畫、錄音／語音與無障礙表現**。

### 為什麼不是立刻自動接 AI？

此版優先排除介面節奏和動畫的問題，為兒童衝突事件建立可控的引導。日後需在完成兒少安全、真人接手機制、輸入保護與專家效度審核後，才可把 AI 事實重述或換位反思接入正式語音介面。
## v0.3：Gemini 2.5 Flash 語意回饋（教師限定虛構案例）

後端 `api/reflect.mjs` 已由 Vercel AI Gateway／GPT 改為 **直接使用 Google Gemini API**，模型固定為 `gemini-2.5-flash`。網站保留七階段及單題回應，AI 僅以當題答案與有限前文產生個別回覆與表情。

需要在 Vercel 專案安全設定 `GEMINI_API_KEY` 才能真正呼叫模型；設定前會退回固定引導。請參考 [AI_PILOT.md](./AI_PILOT.md)，且勿用真實學生衝突故事試驗。

Google 已限制部分新帳戶存取 Gemini 2.5 系列；請先確認金鑰所屬專案有模型權限。
