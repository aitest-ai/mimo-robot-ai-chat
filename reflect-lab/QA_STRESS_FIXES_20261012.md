# Mimo 心晴之鏡｜高情緒壓力測試後的系統修正（2026-10-12）

## 測試背景

先前以 8 回合虛構學生案例，實際呼叫正式部署的 Gemini 2.5 Flash API，測試「作品被改／老師叫忍耐／想摔物品／拒絕冷靜／不想上學／被嘲笑／不願換位／擔心動手」。

**已觀察到的弱點**
1. 表達想把桌面物品掃下去時，Mimo 只有安慰，沒有優先提示避免傷害。
2. 「不想上學」且提及反覆取笑時，Mimo 卻繼續問「怎麼笑的」，未優先確認安全與支援。
3. 明顯拒絕冷靜、換位時，固定流程仍可能在下一輪把學生帶回事實或換位問題。
4. 學生想動手時，依賴 Gemini 回傳 `needsAdult`；模型漏判、斷線或 API 未啟用都可能錯失分流。
5. 求助畫面只以「有人傷害你」為措辭，沒有照顧「學生自己怕傷到別人」的情境。

## 本輪已直接更新的正式系統

### 三層守護，不把安全交給單一模型

**第一層（瀏覽器）**：每次學生提交文字，先執行本地規則。對於明確的立即危險，不等待 Gemini API，直接提示拉開距離與尋求現場大人協助。對於想摔物品，先暫停討論並問是否能遠離桌面。對於反覆被嘲笑或不想上學，優先確認目前安全。這些規則是保守的試作守門機制，**不是臨床評估或霸凌調查**。

**第二層（Vercel API）**：`api/reflect.mjs` 同樣設有立即傷害／物品／學校困擾／拒絕強迫情緒調節的前置回應。不能只倚賴前端，也不會讓 Gemini 覆寫固定的緊急成人轉介。

**第三層（Gemini 2.5 Flash）**：對一般虛構人際事件持續提供情境化回覆和單一追問；提示詞加入「學生抗拒時不強迫，持續被排擠時優先支持」；模型回傳 `needsAdult` 時仍會觸發成人協助鎖定。

### 對話控制修正

- 新增 `safePause`：先留意周遭物品和身體安全，再給孩子「我已退開／找大人／我還是很激動」的選項。情緒沒有立即下降也不算失敗。
- 新增 `supportCheck`：被反覆取笑、排擠、學校拒絕時，先問「現在安全嗎」，不追問當事人嘲笑的細節。
- **拒絕體諒、原諒、換位思考**：直接尊重，轉向孩子希望如何得到支持、保護自己的界線，不再強制扮演衝突另一方。
- **拒絕冷靜、呼吸**：不再強迫呼吸；允許繼續把心事說出來。
- **明確想傷害自己或別人**：停止一般對話，優先成人協助；關閉對話框不能立即繞過分流。
- 求助內容依「可能自己動手／想摔物品／校園困擾／一般受傷害」顯示不同說明，清楚指出**系統沒有自動通報功能**。
- Mimo 在情緒升高時以**穩定、傾聽**的表情陪伴，而不是跟著露出生氣的臉。
- 提升常見繁體中文說法辨識，例如「我不要再上學了」「同學每天笑我」「老師每次都不理我」；並檢查「我不想打她」等否定句避免誤判。

### 後端真實 API 檢查

此前使用正式 Gemini API 取得 8 回合生成回覆並檢視 `needsAdult`；本輪 API 檢查亦確認物品危險會回傳 `source=safety-pause`、拒絕強迫換位會回傳 `source=refusal-respected`、立即傷害會回傳 `source=safety-rule`。曾發現「我不要再上學了」沒有被早期的固定規則涵蓋，後續已修正字詞變體。**修正後的所有語句仍需持續驗證真實案例的敏感度與誤判率**。

## 已知限制與研究倫理

- 關鍵字／規則式初篩不可涵蓋所有說法、反諷、否定句、文化語境與非文字危險訊號；任何未經驗證的系統都不能承諾全面辨識危機。
- 模型有機會產生過度確定、把猜測當事實、太快鼓勵原諒或不恰當的心理推論；正式國小使用前應由專業輔導人員審查腳本、壓力測試與真人接手 SOP。
- 即時危險時，真正的成人介入與法定通報不能靠這個純聊天系統取代；提示框**不會自動通報**。
- 目前只限教師確認的**虛構案例**，不得把真實學生衝突事件／個資輸入公開試作。正式引入要完成兒童隱私、監護人／學校程序及安全審查。
- 模型端的教師共享測試碼曾在對話中公開展示；正式課堂前務必輪替，並設置模型用量與跨函式執行個體的可靠限流。

## 後續優先順序

1. 與學校輔導教師共同審查「學校拒絕」「持續排擠」「可能動手」「自傷線索」的判斷與轉介話術。
2. 建立真實帳號／匿名課堂授權、服務額度、學校真人接手流程，而非共用測試碼。
3. 用足夠的虛構語句變體與人工雙評量測敏感度、特異度與不公平負面效果；經過審核後才做前導教學研究。
