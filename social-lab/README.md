# Mimo 校園小劇場｜Social Lab（國小版）

這是一個提供國小中、高年級體驗的 **校園人際互動練習原型**。學生走進與自己生活有關的小劇場、觀察故事發生、選擇怎麼說，再回頭思考「說話的意圖、對方可能的感受、自己的界線」。

## 六個臺灣國小日常情境

1. **美勞課的最後十分鐘**：分組做海報，時間快不夠了，怎麼跟動作慢的同學說？
2. **水壺倒下的那一秒**：下課時打翻水壺，旁邊同學覺得好笑，該怎麼做？
3. **誰拿走了我的橡皮擦？**：自習時，東西被沒先問過的同學拿去用，怎麼表達界線？
4. **下課十分鐘，誰可以一起玩？**：操場玩球，新的同學想加入，怎麼兼顧規則與友善？
5. **掃地時間的最後一袋垃圾**：放學前，掃地區的工作還沒完成，怎麼分工？
6. **營養午餐的排隊小插曲**：同學說很餓想插隊，怎麼拒絕又不傷害對方？

## 小劇場的互動方式

- 每關四幕，可自行按 **「繼續故事」**，也可直接 **跳過故事**；
- 由原創 SVG 畫出**教室、操場、兩位虛構學生、桌椅、文具與場景物件**；
- 加入微動畫：畫筆移動、水壺倒下與水花、橡皮擦移動、球滾動、掃把動作、午餐餐盤移動；
- 被選擇的回應會影響角色**持續顯示的表情**，進而出現角色的下一句話與故事後續；
- 選擇後**不立即判分**：先看事件後續，再聽角色可能的說法、觀看另一種可能；
- 不想從 A/B/C 選也可自行打字寫一句話，透過自我檢核三個問題反思；
- 同個故事可以重玩，沒有總分、排行榜或失敗懲罰；
- 支援手機，並尊重系統「減少動態效果」設定。

### 設計核心

**好好說話不是讓每個人都開心。** 可以禮貌拒絕；尊重他人，也能清楚說出自己的需要。表情僅表示**虛構角色的一種可能反應**，不能當作真實他人內心的證據。

## 驗收與限制

- 這是固定分支的前端網頁：**無 Ollama 連線、無即時生成 AI，也無自動語句評分**。
- 不收集使用者身分，不設定後端或對話儲存。重新整理時會清空尚未完成的練習。
- 已執行 JavaScript 語法驗證與模擬 DOM 流程測試；**真實瀏覽器跨尺寸的視覺、動畫渲染仍需進一步驗收**。
- 尚無正式教學成效研究，不能宣稱提升同理心或減少霸凌已獲證實。
- 教師應檢視班級文化、學生識讀程度與情境適切性，避免把特定選項當成唯一標準；遇到真實衝突或霸凌須依學校程序由真人協助。
