# 心晴小屋 · Mimo 心情陪伴 UI 試作

這是為國小學生設計的**互動介面概念驗證**，不是 AI 心理師、心理治療、危機服務或已具備兒少安全驗證的正式學生輔導系統。

## 試作內容

- 選心情天氣（6 種，含「說不上來」）
- 感受強度（1–5）
- 簡單描述事件或選擇不想說
- 自主選傾聽、想辦法、休息、找大人
- 模擬聊天、心情回顧、真人求助資訊

## 保護兒少的限制

- 本頁沒有後端、資料庫或 AI API。聊天僅是固定規則示範，**不是心理諮商**。
- 本頁不會儲存、上傳或傳送學生輸入；重新整理即消失。公開展示請勿輸入真實姓名、學校、地址、電話或其他敏感資料。
- 高風險提醒只是少量關鍵字示範，存在漏判與誤判，不能據此宣稱安全，也不得直接用於真實學生危機處理。
- 網頁沒有真人通報管道，也**不會自動通知老師或家長**。如有急迫危險，需直接尋求可信任的真人與正式資源。
- 正式部署需建立人工介入與危機 SOP、明確角色權限、法規與隱私審查、取得必要的校園或監護人授權、兒童測試及定期安全驗收。

## 原始動畫元件

這個免建置試作版使用原生 SVG/CSS 重繪機器人，而非直接套用 `robot-heads` React 套件。這一版優先驗證 UI、流程與**持續不閃爍的情緒動畫**。正式產品可改用 [Robot Heads](https://github.com/fayazara/robot-heads) 做同樣的狀態流程。
